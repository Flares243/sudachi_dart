# sudachi_dart_example

A Flutter app demonstrating the `sudachi_dart` plugin — load a dictionary, enter Japanese text, and tokenize it with selectable split modes.

## Setup

1. Download **SudachiDict_full** from [SudachiDict releases](https://github.com/WorksApplications/SudachiDict/releases).
2. Extract `system_full.dic` and place it at:
   ```
   assets/sudachi/system_full.dic
   ```
   `sudachi.json` is already present in that folder.
3. Run:
   ```sh
   dart pub get
   flutter run
   ```
